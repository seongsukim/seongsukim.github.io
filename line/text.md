# Line

If you look up and stare at the sky, you can see the lines.

Looking at those lines, I could not remember the role of the line. I just thought it was "beautiful twisted."

This work began with the same idea as the previous pattern series. The electric lines that could easily be seen in any place were suddenly visible. It is aesthetics of the line which is different from the pattern of various patterns which we did before.

Is there anything that comes to mind when I look at the title of a photo ...? Try putting that number into the Google Maps search box, and you'll see some funny scenes.

This is a task that can be done anywhere in the world. It has the same context as the previous pattern series. I want to make a world map with my own eyes. It's sort of like a collection. It is really interesting.
